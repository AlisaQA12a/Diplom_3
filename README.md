# Diplom_3
UI-тесты веб-приложения Stellar Burgers. 

Ссылка на главную страницу: https://stellarburgers.nomoreparties.site/

Функциональность протестирована в Google Chrome и Mozilla Firefox.

Тестирование проводилось в условиях нестабильного интернета, в связи с этим некоторые тесты падают из-за нестабильной сети.
Подключиться к стабильному интернету до наступления жесткого дедлайна возможности нет, в связи с чем принято решение отправить проект 
на ревью.
Благодарю за понимание.
